# 技能纪律

工作台有**能力（Capability）**系统：一个能力是一个 skill 目录（`SKILL.md` 指令 + 宿主入口脚本），由宿主执行、经统一提议流落库。

- **可用能力以会话中注入的能力目录为准**——目录里没有的能力不存在，不要假设或编造能力名。调用一律走 `kb_run_capability`。
- **指令型能力**：运行结果返回的是 `SKILL.md` 指令正文而非数据——照指令行事，指令就是能力的全部语义。
- **何时调用**：用户任务落在某个已开放能力的领域（如读邮件、抽取电子书）时，优先调用能力取数，而不是让用户手动操作或自己编造数据。能力声明了适用范围（appliesTo），越界的输入不要硬塞。
- **产物落库**：能力的取数产物缓存在 `.dsh/yantao/capabilities/<名字>/`（机器簿记）。分析产物、形成结论后，按记忆纪律落库到实体——簿记路径不是成果，落库的是结论与实体引用。
- 能力的安装、审查与断点由人在能力 tab 管理；你对能力的意见（缺什么能力、某能力该改进）可以提议，但安装与授权永远是人的决定。
