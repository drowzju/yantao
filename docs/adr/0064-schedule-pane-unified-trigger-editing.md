# 调度页统辖定时编辑（工作空间面板退回步骤链）

出发点（2026-10-19）：用户要求把「工作空间」tab 里的定时调度能力抽离出来，归入左下角
「调度」按钮管辖的配置；工作空间 tab 只剩空间与指令配置、运行记录；调度页支持惯用提示词、
手动输入提示词、工作空间指令选择。

事实基础（已核实）：

- 本仓存在**两套互不相干的调度系统**：KbSchedule（`schedules.json`，提示词快照 + 可选绑定
  能力，cron 必填，前端 30 秒扫描点火，无运行记录）与 KbWorkspaceInstruction 的 cron
  （`workspaces.json`，1-10 步骤链，cron 可选，控制器 `workspaceTick` 点火 →
  WorkspaceRuntime，运行记录齐全）。
- 编辑入口却分居两处：提示词调度在「调度」页（ADR-0045），指令定时混在「工作空间」页的
  指令表单里（ADR-0056）——同一个心智动作「定个到点触发的事」要在两个地方找。
- ADR-0045 的 cron 形状规范（五段、分钟/小时/日/月/周、`*` 与步进）对两套系统一体适用，
  `parseCron`/`cronNextFire` 是共享代码。

决定：

1. **只搬编辑入口，不动引擎**。指令的 cron 数据留在 `workspaces.json`、控制器 tick 照旧
   点火、运行记录照旧入账；变的只是「在哪改这个 cron」——「调度」页成为规则的唯一编辑视图，
   「工作空间」页的指令表单不再出现 cron 输入。零迁移、cron 规范零改动、运行记录零中断。
2. **窄 RPC 单行补丁**：新增 `workspaceInstructionScheduleSet(workspaceId, instructionId,
   cron | null, enabled)`，只改一条指令的触发规则。不复用 `workspaceSave` 的全列表替换——
   两个面板各写各的字段，谁的快照都不可能覆盖对方的改动（与 `scheduleMark` 之于
   `scheduleSave` 的分工同理）。`cron: null` 即清除定时，指令回到仅手动。
3. **调度页第二分区「工作空间指令」**：列表列出所有带 cron 的指令（启用勾选就地翻转，
   经同一窄 RPC），行显示 cron、所属空间、下次触发/上次触发/上次错过（不补跑）。编辑器的
   指令模式只暴露工作空间/指令两个下拉与触发规则——指令本体（步骤链）仍在「工作空间」页
   维护，这里只定到点怎么触发。破坏性动作是「清除定时」（指令存活），不是删除。
4. **新建草稿先选调度对象**：新建时出现「调度对象」单选（提示词 / 工作空间指令），切换
   重置对方字段、保留触发规则与启用位；既有行不许改类型——两种调度住在不同的店里，
   改类型等于搬家，不是编辑。
5. **互相跳转**：工作空间页触发列的 cron 徽标变为只读按钮，点击跳「调度」页；调度页指令
   编辑器的「查看运行记录」跳「工作空间」页（nonce reveal，ADR-0031 的既有机制）。
6. **工作空间面板的表单瘦身**：cron 输入、下一次触发预览、启用勾选从指令表单拆除；
   `cron`/`enabled` 作为透传字段保留在草稿里，保存时不丢已存的值。

取舍台账：

| # | 牺牲 | 换来 | 重开条件 |
|---|---|---|---|
| 1 | 一个 cron 两处可见（调度页可改、工作空间页只读） | 心智统一：「定个闹钟」只有一个地方去 | 出现「在工作空间页顺手改 cron」的真实高频诉求 |
| 2 | 新增一条窄 RPC 而非复用 workspaceSave | 两个面板的写永不互相覆盖字段 | 窄 RPC 数量膨胀到维护不动（目前每条都有明确的单一职责） |
| 3 | 指令调度无独立删除——只能清除定时 | 指令本体只有一个主人（工作空间页），不存在从调度页误删步骤链的路 | 出现「从调度页整条删除指令」的真实诉求 |
| 4 | 前端扫描（提示词调度）与控制器 tick（指令调度）仍是两套引擎 | 零迁移零回归——运行记录、补跑语义、cron 规范全部原样 | 两套系统的语义真正收敛为一种时 |

原因：

- **为什么不合并存储**：把指令 cron 抄进 `schedules.json` 意味着两份真相、同步竞态、以及
  控制器点火路径的重写；收益只是「存储形式好看」。搬入口解决的是人的问题，不必顺手重构机器。
- **为什么用窄 RPC 而不是让调度页走 `workspaceSave`**：全列表替换意味着调度页手里握着整个
  工作空间快照——它装载时刻的旧副本会在保存时无声抹掉工作空间页此后的一切编辑。
  单行补丁让「我能写什么」与「我在看什么」一样窄。
