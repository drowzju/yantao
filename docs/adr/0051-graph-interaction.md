# 图谱交互升级（过滤·聚焦·缩放平移）

出发点（2026-10-07 裁决）：ADR-0049 落地的图谱 tab 是一张静态全景——单击即打开实体、
无缩放平移（当时刻意推迟，台账 #4）、三类边混在一起无过滤。个人库渐大后一屏开始拥挤，
且三类关系叠画让人无法只看某一类。本轮把图谱从"看一眼"升级为"可操作"：视图过滤、
单击聚焦、双击打开、缩放平移拖拽。

事实基础（已核实）：`GraphPane.tsx` 纯 SVG 自绘，viewBox 1000×700 一屏适配，交互仅有
节点拖拽（钉死+局部重热）与短位移判点击；`edgeKindOf` 已能在渲染侧由端点推导边类型；
`degreesOf` 已算每节点度数；图例是右上角静态列（`pointerEvents: 'none'`）。布局层
`graphLayout.ts` 纯函数、不感知过滤。

决定：

1. **视图过滤，人-人永久必显**：三种边视图中，`person-person` 是基座——没有开关、
   永远显示；`area-project` 与 `person-project` 各带勾选框，可独立开关。控件就地升级
   现有图例：人-人行保持纯图例，另两行加勾选框。勾选状态不持久化，每次进 tab 回到
   默认（仅人-人）。
2. **过滤按端点筛节点，孤点例外保留**：可见节点 = 所启用边类型的端点集合，不在集合
   的节点不参与布局（切换即重排，个人库成本可忽略）。全图度为零的孤立节点不受过滤
   影响、始终弱化保留——ADR-0049「沉默也是信息」的理由不因过滤失效，孤点不属于任何
   边类型，把它交给过滤器裁决等于让它永远消失。
3. **单击聚焦，双击打开**：单击延迟 250ms 执行（给双击让路，双击事件先到则取消聚焦
   定时器）——视口缩放平移使该节点居中（目标倍率 2x），该节点放大 1.4 倍、相邻边加粗
   （1.5→3），非邻居节点与非相邻边淡化（透明度 0.15）。布局不动，纯视口变换，与缩放
   平移共用一套机制。聚焦中单击其他节点（无论是否邻居）直接切换焦点；退出走点空白处
   或再点同一节点，退出后还原聚焦前视口。双击 = 既有 `openFile(path,'edit')` 打开实体
   编辑 tab，仅入口从单击挪到双击，不新建详情页。
4. **缩放平移拖拽分工**：滚轮=缩放（0.5x～4x 夹住，光标为锚点）；拖空白=平移；拖节点=
   移动节点（现状保持，坐标换算加入视口逆变换）。缩放平移推翻 ADR-0049 决定 5 的
   「刻意不做」，单击/双击分工推翻其「短位移判点击打开实体」。

取舍台账：

| # | 牺牲 | 换来 | 重开条件 |
|---|---|---|---|
| 1 | 过滤切换即重排布局，拖过的位置丢失 | 实现极简（重建布局），图面清爽 | 用户实际抱怨位置跳动时做位置续接 |
| 2 | 单击响应延迟 250ms | 单/双击语义干净的分离 | 有用户反馈单击迟钝时改即时聚焦+双击容忍闪烁 |
| 3 | 默认只见人-人，首屏没有项目 | 图面最简，人的协作网络是主角 | 默认组合被证明不合用时调默认勾选 |
| 4 | 平移无边界夹持 | 实现简单 | 实际迷失在空图区时加软夹持 |

原因：

- **为什么人-人是基座而不是三个平权的开关**：工作台的主语是人——人-人边是最稀疏也
  最难从别处看到的信息（人-项目在项目页可见，领域-项目在项目 frontmatter 可见），
  只有协作网络没有别的替身。让它不可关闭，是把这个视图的独特价值钉死在默认态。
- **为什么聚焦是视口变换而不是子图重构**：动布局毁掉用户的空间记忆，动视口则随时
  可逆且与缩放平移天然同构——一套 `(k, tx, ty)` 状态，聚焦只是它的一个预设值加动画。
- **为什么单击延迟而不是双击容忍闪烁**：聚焦是带动画的状态切换，先聚焦再打开会在
  双击路径上闪一次无意义的居中动画；250ms 在浏览场景低于察觉阈值。
- **为什么勾选不持久化**：个人库重开成本为零，少一处持久化状态；真有固定组合需求
  再谈 localStorage。

后果：

- `packages/client/ui-yantao`：`graph/subgraph.ts`（过滤纯函数）、`frame/GraphPane.tsx`
  （视口状态机、聚焦、图例勾选、滚轮缩放、空白平移）、`Frame.tsx` 的 `onOpen` 挪到
  双击回调。
- ADR-0049 正文不动；其台账 #4（无缩放平移）由本篇决定 4 清偿，「短位移判点击」由
  决定 3 取代。
- 无 RPC、无 kb 包改动。

落地注记（2026-10-07 完工）：

- 视口状态 `(k, tx, ty)` 施加在内层 `<g transform>`，viewBox 保持 1000×700；屏幕→图
  坐标换算集中在一个反变换函数里，节点拖拽与滚轮锚点共用。
- 聚焦动画用 rAF 缓动 ~300ms；聚焦保存进入前视口，退出还原。
- 过滤纯函数 `visibleSubgraph` 单测覆盖：端点筛选、孤点保留、人-人恒在。
